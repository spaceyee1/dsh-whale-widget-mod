# v1.0.3：插件独立 Key 余额兼容

修复已有插件 Key，但旧版 DSH 没有账户余额服务时无法显示余额的问题。内部版本为 `0.3.16-companion.14`，这是小鲸鱼挂件更新，不要求升级 DSH 桌面主程序。

在“插件 API”中选择 DeepSeek 官方服务，填写 Key、确认地址并保存即可查询余额。查询固定为 `GET https://api.deepseek.com/user/balance`，只发送认证，不发送对话；聊天模型可以稍后选择。此前在同机同 Windows 账户已经保存并确认的官方插件 Key 可继续使用。

存在该配置时优先显示插件 Key 所属账户余额；请求失败不会换用另一个宿主账户。没有配置该官方 Key 时仍支持原来的 DSH 账户服务。未登录、Key 无效、存储损坏或网络错误继续明确报错，不会读取主聊天 Key 或从环境变量寻找替代凭据。

模型列表、账本、预警、预算、余额校正、人设、AI 插话和角色气泡保持原有功能。账本按来源及凭据引用隔离；更换 Key 会建立新的观测基线，不把两个 Key 的余额差当成消费。账本仅记录观测到的账户余额变化，不能等同于本挂件的请求费用。

已有本机同源、宿主认证、目的地绑定、证书验证、请求取消与 Windows DPAPI 存储保持生效。自定义服务商，即使填写同一个官方域名，也不会被视为官方预设。其他厂商和中转 Key 不发送给 DeepSeek 余额接口。更新不改变原有图片、动画、音效或素材归属。

## 验证

回归覆盖真实路由注册、未提供宿主账户服务、插件 Key 查询、零余额、格式异常、未确认目的地、非官方配置、并发缓存、换 Key 取消、账本隔离和宿主凭据访问拦截。测试只用模拟 Key 和网络。

2026-10-15：全套 `npm test` 共 **44 项通过**。本机 DSH 桌面 5.3.6 上安装后，经过宿主认证的实际余额接口返回 `HTTP 200`、`ok: true`、`balanceSource: plugin-api`；模型列表和账本接口也均成功。验证直接使用本机已保存的官方插件 Key，没有输出 Key 或调用聊天模型。已确认实际加载内部版本 `.14` 和菜单版本 `v1.0.3`。

这证明当前本机安装与余额通道可用；反馈者电脑上的网络、系统和宿主环境尚未远程验证。
