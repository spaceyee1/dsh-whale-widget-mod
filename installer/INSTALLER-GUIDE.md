# DSH 小鲸鱼 v1.0.3 安装说明

这是 Windows x64 小鲸鱼挂件安装器，需要电脑已安装并运行过 DeepSeek Harness（DSH）。安装挂件不需要另外安装 Node.js、npm 或插件安装工具，也不会升级 DSH 主程序。

1. 退出 DSH，双击 DSHWhale-v1.0.3-Setup-x64.exe。
2. 核对自动找到的 DSH 配置目录。常见桌面版是 用户目录\.dsh\profiles\web-desktop；浏览器版可能是 web。自定义环境请用“选择”指定实际 profile，不要选择 DSH 程序目录。
3. 点击“安装到 DSH”。已有插件代码会备份，已有 Key、账本、角色与设置保留。
4. 重新打开 DSH。如果小鲸鱼之前被关闭，到“设置 → 插件 → 管理”启用小鲸鱼。菜单应显示 v1.0.3。
5. 在“插件 API”选择 DeepSeek 官方服务，填写自己的 Key、确认地址并保存。余额无需选择模型即可查询；AI 插话还需选择模型并保存，再点击“开始”。

升级会从已有插件中保留角色图片、动图和音效。首次安装没有角色素材时提供简易蓝鲸占位图，可以通过挂件的自定义角色功能更换。安装器不内置原包媒体，不自动下载素材；缺少原音效时不会发出对应声音。

标准 DSH EAC 5.x 桌面环境同时更新启动覆盖层，避免下次启动恢复旧挂件；其它自定义 profile 只修改选中的插件目录。宿主将来内置比此包更高的版本时，安装器会明确提示兼容限制。DSH 6.x 等隔离环境的路径和实际加载机制需要按其宿主确认，未在本机验证。

自动注册支持常规块状 YAML 配置。使用链接式插件目录或复杂、自定义 patch 的环境，请用“仅解压插件文件”后通过宿主插件管理器安装。

更新不读取主聊天 Key，不包含制作者的 API Key、账户配置、对话或账本。Windows 上已保存的插件 Key 仍由同一 Windows 账户解密。
